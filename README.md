# Car-Sales-Analysis-Project

## Project Overview
Analyzed car sales data using MS Excel to identify key trends in sales trend over time, top companies by market share, etc.  Also, built a dynamic dashboard with pivot tables, charts, and slicers to support data-driven decision-making.

## Tools used :
- Excel
- Pivot Tables
- Data Validation
- Conditional Formatting
- Charts
- Slicers
- Advance Formulas such as lookups, index, sumifs, countifs, etc.

## Key Insights :
- Top selling car models identified
- Found the market share % by brand
- Did YoY brand wise growth analysis
- Found segment wise sales
- etc.
